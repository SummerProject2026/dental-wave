DENTALWAVE ASSISTANT SCHEDULER
================================

TO START
1. Plug in the DentalWave USB drive.
2. Open the USB drive.
3. Double-click "OPEN DENTALWAVE.bat".
4. On the first start only, create a shared user password of at least 12 characters.
5. Wait for your normal web browser to open.
6. Log in with username: user

Your password is the one you created on the first start. DentalWave does not
save a readable copy of it. Keep it somewhere secure.

TO CLOSE
1. Finish and save your work in DentalWave.
2. Close the browser tab.
3. Double-click "CLOSE DENTALWAVE.bat".
4. Wait until the window says DentalWave has stopped and a backup was created.
5. Safely eject the USB drive.

IMPORTANT
Never unplug or eject the USB while DentalWave is running. Always use
"CLOSE DENTALWAVE.bat" and wait for confirmation first.

BACKUP
DentalWave automatically creates a dated backup after a clean close and keeps
the 7 most recent backups in the backups folder.

To make an extra backup:
1. Close DentalWave first.
2. Double-click "BACKUP DATA.bat".

TROUBLESHOOTING
- If DentalWave is already running, OPEN DENTALWAVE opens it in your browser.
- If port 8080 is being used by another program, close that program and try again.
- If DentalWave does not open, double-click "OPEN DIAGNOSTICS.bat". A readable
  report will be saved beside the launcher and opened automatically in Notepad.
- Keep the whole DentalWave-Portable folder together. Do not move individual files.
- This application is available only on this computer at http://127.0.0.1:8080.
